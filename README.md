# Офис агентов — отдельный проект

Рабочая серверная основа для интерфейса Claude: постоянная SQLite-база, поиск по настроенным RSS/Atom-источникам, оценка объявлений, журнал запусков и PDF-отчёты. Репозиторий TorgiFinder-AI не используется.

## Запуск на ПК или VPS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
OFFICE_TOKEN='придумайте-длинный-секрет' uvicorn server:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000` (на сервере обязателен HTTPS). При первом входе введите ключ `OFFICE_TOKEN`. Храните его в секрете; он даёт доступ к данным. Для тестового запуска без `OFFICE_TOKEN` доступ разрешён только с локального компьютера.

Для автоматического запуска работает расписание по Красноярску: понедельник и четверг в 11:00, **при условии, что сервер постоянно запущен**. Кнопка «Обновить отчёт» запускает цикл вручную.

## Источники

Добавьте URL официально предоставляемых RSS/Atom-лент через `POST /api/feeds` с JSON `{"url":"https://...","name":"Название"}` и заголовком `Authorization: Bearer <OFFICE_TOKEN>`. Источники, не отдающие RSS/Atom, потребуется подключать отдельными разрешёнными интеграциями. Пустой список источников не создаёт фиктивных объявлений. Для проверки работы можно добавить объект через `POST /api/items`.

## Ограничения

- Система не обходит капчи и ограничения сайтов, не рассылает сообщения продавцам.
- Риск и прибыль — предварительная оценка по доступным данным, не юридическое заключение и не подтверждённая рыночная цена.
- Пока нет независимых данных о цене перепродажи, объект помечается как требующий проверки, а не получает выдуманную маржу.
- Для постоянной публикации нужны VPS/другой сервер и HTTPS; GitHub Pages один не исполняет backend.
